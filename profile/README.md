# EveryFrame Studio
### The Generative Media Execution Layer on Bittensor

We’re building a creative workspace that brings AI video, image and audio generation together—from the first idea to the final screen.

**EveryFrame.Studio** brings generative models, creative assets and editing workflows into one environment.

**Bittensor Subnet 117** is designed to connect real generation requests with competitive, verifiable execution through independent miners.

Our ambition is to connect creators, developers and businesses with infrastructure powered by the wider Bittensor network.
